# M08 设置与响应式界面

## 模块目标

让现有静态布局完全读取严格的 Settings 和业务 Store，并补齐 Provider、Assistant、Topic、导入导出等数据管理入口的状态反馈。

## 子任务

- [x] 收紧 SettingsPanel。
  - 输入：PRD 4.6 的 `Settings` 字段。
  - 输出：只展示并写入声明字段的设置面板。
  - 完成判定：不存在 `sendMessageShortcut`、`topicPosition` 等未声明字段。

- [x] 连接设置即时效果。
  - 输入：主题、字号、消息样式、代码设置、发送快捷键、Token 开关。
  - 输出：组件响应式更新和持久化。
  - 完成判定：修改设置无需刷新即可生效，刷新后保持。

- [x] 完善数据管理 UI。
  - 输入：导入文件、导出校验结果、保存状态、Provider/Assistant 删除结果。
  - 输出：成功、失败、警告和禁用操作的明确 toast/dialog 文案。
  - 完成判定：不会静默失败或在校验错误时显示成功。

- [ ] 响应式回归。
  - 输入：桌面、平板和移动端视口。
  - 输出：三栏、双栏、抽屉和底部导航的正确切换。
  - 完成判定：所有操作文本不溢出，图标按钮有 tooltip 或可访问名称。

## 验收

- [ ] 关键操作可在桌面和移动端完成。
- [ ] 页面无静态假数据覆盖业务 Store 数据。
- [x] `npm run build` 通过。
