# 17 - 响应式布局

> 需求来源：§3 F-08 布局, §5 非功能需求  
> 优先级：P1  
> 目标：桌面三栏 / 平板抽屉 / 移动端底部导航

## 任务清单

### 17.1 桌面布局（≥1200px）

- [ ] 三栏布局：侧边栏（Assistant + Topic）+ 消息区 + 会话检查器
- [ ] 侧边栏可折叠
- [ ] 会话检查器可折叠
- [ ] `narrowMode=true` 时强制窄模式

### 17.2 平板布局（768px–1199px）

- [ ] 隐藏固定会话检查器
- [ ] 提供抽屉入口按钮
- [ ] 点击打开会话检查器抽屉
- [ ] 侧边栏保持可见或可折叠

### 17.3 移动端布局（<768px）

- [ ] 底部导航栏：对话、助手、设置
- [ ] 侧栏抽屉：从左侧或右侧滑出
- [ ] `navbarPosition` 控制导航栏位置
- [ ] 消息区全屏
- [ ] 输入框固定底部

### 17.4 布局组件

- [ ] 创建 `src/components/AppLayout.vue` 主布局容器
- [ ] 创建 `src/components/Sidebar.vue` 侧边栏
- [ ] 创建 `src/components/Inspector.vue` 会话检查器
- [ ] 创建 `src/components/BottomNav.vue` 移动端底部导航

### 17.5 响应式断点

- [ ] 使用 CSS `@media` 或 VueUse `useBreakpoints`
- [ ] 断点：mobile < 768px, tablet 768-1199px, desktop ≥ 1200px
- [ ] 切换时平滑过渡

### 17.6 移动端交互

- [ ] 左滑：切换 Topic（上一个/下一个）
- [ ] 右滑：打开侧栏抽屉
- [ ] 底部导航切换主要视图

### 17.7 功能完整性

- [ ] 所有断点下可完成：新建对话、发送消息、切换模型、打开设置、管理 Topic

## 验收

- 桌面/平板/移动端布局正确
- 所有断点下核心功能可用
- 抽屉/底部导航交互流畅
- narrowMode 设置生效
