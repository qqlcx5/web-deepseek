# 03 信息架构

## 3.1 现状与问题

当前只有单一"对话页"（侧栏 + 消息 + 输入），新增的"阅读 / 记忆库 / 同步"没有归属。需要从单页升级为**多视图应用**，同时不让对话体验变重。

## 3.2 推荐信息架构：左侧导轨 + 主区

```
┌──────┬─────────────────────────────────────────────┐
│ 导轨  │            主区（随视图切换）                  │
│ Rail │                                              │
│ 💬   │  对话视图 / 阅读视图 / 记忆库视图 / 设置视图     │
│ 📖   │                                              │
│ 🗂️   │                                              │
│ ⚙️   │                                              │
│ ───  │                                              │
│ 🌗👤 │  主题切换 · 用户/数据状态                       │
└──────┴─────────────────────────────────────────────┘
```

**一级视图（4 个）：**

| 视图 | 图标 | 核心 |
|---|---|---|
| 对话 Chat | 💬 | Assistant/Topic 侧栏 + 消息流 + 输入框 |
| 阅读 Reader | 📖 | 抓取栏 + 文档预览（Markdown/Raw/Metadata）+ "基于此文档对话" |
| 记忆库 Library | 🗂️ | 搜索 + 文档列表 |
| 设置 Settings | ⚙️ | 分组设置（外观/输入/Provider/Assistant/上下文/抓取/同步/数据） |

**导轨底部：** 主题切换、数据/同步状态指示、用户名（可选）。

## 3.3 备选 IA（供权衡）

- **B. 对话为中心 + 抽屉**：对话为主屏，阅读/记忆库/设置作为抽屉/模态。优点是对话沉浸感强；缺点是阅读/记忆库沦为二等公民，导航不清晰。
- **C. 顶部 Tab**：四个 Tab 平铺顶部。优点是发现性强；缺点是顶栏拥挤、移动端难放。

> **推荐 A（导轨）**：扩展性好、移动端可降级为底部导航、各视图地位平等。

## 3.4 视图间跳转规则

| 触发 | 行为 |
|---|---|
| 记忆库点文档 | → 阅读视图（加载该文档） |
| 阅读视图"基于此文档对话" | → 对话视图，文档作为上下文挂载（顶栏 banner 显示） |
| 对话中"抓取网页"入口 | → 阅读视图抓取栏 |
| 设置改外观 | 当前视图即时生效，不跳转 |
| 命令面板 | 任意视图 Cmd/Ctrl+K，可跳任意 Topic/文档/设置项 |

**不丢状态原则：** 切换视图不清空对话草稿、不中断流式、不重置当前文档/模型。

## 3.5 响应式布局

### 桌面 ≥1180px

- 导轨（固定窄列，~60px 图标）+ 主区。
- 对话视图：主区内再分 [Assistant/Topic 侧栏 276px] + [消息区] + [检查器 304px，可关]。
- 阅读视图：[抓取栏 顶] + [预览主区] + [对话抽屉 右，可开]。
- 设置视图：[分组左栏] + [表单右栏]。

### 平板 760–1180px

- 导轨保留。
- 对话视图：隐藏固定检查器，改抽屉入口；侧栏可折叠。
- 阅读视图：预览主区全宽，对话抽屉覆盖式。

### 移动 ≤760px

- 导轨降级为**底部导航**（对话/阅读/记忆库/设置 4 项 + 安全区）。
- 对话视图：侧栏/检查器均为覆盖式抽屉 + 遮罩。
- 输入区上浮，不被底部导航遮挡（padding-bottom = 底栏高）。
- 所有文字/控件窄屏可用，无横向溢出。

## 3.6 全局层级（z-index 约定）

| 层 | z | 内容 |
|---|---|---|
| 内容 | 0–10 | 视图、侧栏、检查器 |
| 浮层 | 20–40 | 抽屉、下拉、回底按钮 |
| 遮罩 | 55–70 | 抽屉/模态背景 |
| 模态 | 80 | 设置/编辑弹窗 |
| Toast | 100 | 全局提示 |

## 3.7 导航状态持久

- 当前视图、当前 Assistant/Topic、当前 Document、当前模型、各视图滚动位置，刷新后恢复。
- 草稿、未发送附件跨视图保留。
