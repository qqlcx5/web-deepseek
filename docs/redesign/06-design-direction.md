# 06 设计方向与必须修复的痛点

## 6.1 设计原则

1. **本地优先的透明感**：用户要知道"数据在本地、正在保存、正在同步"。保存/同步/离线状态应在顶栏常驻可见，不要藏在设置里。
2. **对话沉浸 + 阅读专注**：对话视图是主屏，密度可以高；阅读视图要留白、专注、可读。两种节奏，不要用同一套拥挤模板。
3. **组件一致性优先于花哨**：必须用 `vue-element-plus-x` 组件库（XSender/Bubble/BubbleList/Conversations/Welcome/Prompts），不要再手写 textarea 和消息卡片——这是旧设计最大的问题。
4. **状态可见**：流式增量、停止、失败、重试、连接测试、抓取进度，都要有清晰、即时的视觉反馈。不要"点了没反应"。
5. **响应式不是缩放**：桌面三栏 / 平板双栏 / 移动底部导航 + 抽屉，是三种不同的交互模型，不是同一个布局缩放。
6. **可访问性是底线**：图标按钮必有可访问名；键盘可完成主要操作；对比度达标。

## 6.2 视觉方向（建议，可由设计师定调）

- **基调**：冷静、专业、克制。品牌紫 `#5b56d6`（light）/`#7c7aff`（dark）作强调，大面积 `--surface` 白/深灰底。
- **密度**：对话区中等密度（消息间距 ~28px，字号 13px / 行高 1.75）；阅读区宽松（正文 15–16px / 行高 1.8，最大宽 ~720px）。
- **层次**：靠 `--surface/2/3` 三级底色 + `--line` 分隔，少用重阴影；浮层才用 `--shadow-md/lg`。
- **圆角**：消息气泡 8px（用户气泡带尖角指向头像）、卡片 6–8px、按钮 6px、底栏胶囊 16px。
- **动效**：克制。流式逐字、状态点呼吸、抽屉滑入（200ms）、hover（140ms）。不要全屏过渡动画。
- **代码**：深色 `--code-bg` 恒定（明暗都用深底），配 `--code-text`，保证语法高亮可读。

## 6.3 当前痛点清单（重设计必须修复）

> 这些是旧界面的真实问题，新设计要逐条解决。

| # | 痛点 | 影响 | 修复方向 |
|---|---|---|---|
| P1 | 输入区是手写 textarea，与组件库割裂 | 风格不统一、快捷键/状态各自实现 | 全面改用 `XSender` + `useSend` |
| P2 | 消息列表手写 `<article>`，流式不增量（响应式 bug） | "发送没流"，体验差 | 改 `BubbleList`+`Bubble`+`XMarkdown`，修复流式响应式 |
| P3 | 没有一级导航，阅读/记忆库/同步无入口 | 新功能用户找不到 | 引入导轨 + 4 视图 |
| P4 | 空状态有两套（手写 + Welcome 未接入） | 重复、不一致 | 统一 `Welcome`+`Prompts` 一处空态 |
| P5 | 侧栏话题列表手写 v-for | 无分组/菜单/虚拟滚动 | 改 `Conversations` |
| P6 | 附件只在输入区预览，消息内只显示文件名 | 已发附件看不出是什么 | 消息内用 `FilesCard` |
| P7 | 模型选择/Provider 就绪状态不可见 | 不知道请求会用哪个模型/是否配置好 | 顶栏上下文 banner + 模型状态 |
| P8 | 连接测试、同步状态无处可见 | 配置完不知道通没通 | 测试状态灯 + 顶栏同步徽标 |
| P9 | 移动端挤压、底部导航与输入区重叠 | 窄屏不可用 | 底部导航 + 输入区 padding + 抽屉化 |
| P10 | 图标按钮无 tooltip/aria | 可访问性差、含义不明 | 全量补可访问名 |
| P11 | 抓取功能无清晰入口与状态 | SPA 抓取体验缺 | 阅读视图抓取栏 + 状态机 |
| P12 | 设置项散乱、部分即时生效部分要刷新 | 改了不知道有没有用 | 分组 + 全部即时生效 |

## 6.4 明确不要做

- 不要写死 AI 身份文案（"你是 XX 助手"）。systemPrompt 来自模型/助手/全局配置；上下文是"事实材料"。
- 不要为破坏性操作（删除/清空/回滚）省略二次确认。
- 不要默认导出 API Key。
- 不要在流式中每个字符写库（已节流，UI 不需关心，但别引入高频重排）。
- 不要把同步做成 entity 级冲突解决 UI（v1 是快照上下传 + 回滚）。

## 6.5 可访问性检查清单

- [ ] 所有图标按钮有 `aria-label` 或 tooltip。
- [ ] 颜色对比度 WCAG AA（正文 ≥4.5:1）。
- [ ] 键盘可达：Tab 顺序合理；Enter 发送/Esc 关闭/Cmd+K 命令面板。
- [ ] 焦点可见（focus ring）。
- [ ] 表单字段有 label。
- [ ] 动画可被 `prefers-reduced-motion` 关闭。
